# qmk-myfn

> **myfn 约定**：一份与具体键盘无关的约定，规定「按住 Fn（myfn 键）时，各个键做什么、在什么条件下才做」。
> 本仓库**只有约定，没有代码、没有库**。是否遵守由各键盘自行实现。

---

## 1. 定位

- 本仓库是一份**约定**，不是代码库。
- 键盘的 Fn 键必须改成 **myfn 键**（按住即进入 myfn 层）。
- 键盘**只实现自己能实现的功能**：能力/条件不满足的功能就不实现（见规则）。
- 约定里不含任何具体键盘内容；键位、动作由键盘自行实现。

## 2. 最高优先级约束

- 键盘**必须保留厂商原厂进入 bootloader（刷固件 / DFU）模式的 Fn 组合键**。
- 该约束的优先级**高于本约定的一切键位映射**：当约定的映射会与该组合键冲突时，**以该组合键为准**。
- 该组合键是「保命键」，任何情况下都不得因 myfn 的键位安排而失效。

## 3. 约束表

| 键位 | 功能 | 前置条件 |
| :-- | :-- | :-- |
| Fn+1 / 2 / … / 0 | F1 / F2 / … / F10 | 无前置 |
| Fn+`-` / Fn+`=` | F11 / F12 | 无前置 |
| Fn+`[` / Fn+`]` | 音量减 / 音量增 | 无前置 |
| Fn+Q / W / E | 蓝牙 1 / 2 / 3 | 支持蓝牙；有物理开关须在蓝牙挡 |
| Fn+R | 2.4G | 支持 2.4G；有物理开关须在 2.4G 挡 |
| Fn+T | 切有线 | 键盘无物理切换按键；有物理开关 → 空跑 |
| Fn+L | 休眠（短按） | 键盘无物理切换按键；有物理开关 → 空跑；USB 有线时 → 空跑 |
| Fn+右上角键 | 唤醒 | 键盘无物理切换按键；睡眠中 |
| Fn+Space | 电量 | 有电池 |
| Fn+Esc | 初始化配置 | 无前置 |
| Fn+Caps | 退出 / 开关 Vim | 键盘实现了 Vim |
| 其余键 | **吞键**（空跑，不输出） | — |

> **未定义键吞键**：myfn 层内，除上表显式声明者外，**所有键（含修饰键）一律吞键**，以避免 `Fn+Shift+Esc` 之类泄漏。
> **唯一例外**：原厂 Fn+bootloader 组合键（§2）在**吞键之前**、用**独立记录的物理修饰键影子**判断（不依赖 `get_mods()`）——因此吞掉修饰键不影响它。

> **休眠 / 唤醒说明**
> - 「右上角键」= **键盘布局右上角那个键**（按布局定，如 `Delete` / `Backspace`），**不得替换为其它键**。
> - `Fn+L` **短按**进入休眠；前置为「键盘无物理切换按键」且「非 USB 有线」，任一不满足 → 空跑（规则 2）。
> - `Fn+右上角键` 是**唯一**唤醒组合；**非该组合的按键不会真正唤醒**——仅瞬时唤醒 MCU 后自动重回深睡，避免误开机。
> - 休眠 / 唤醒非保命键；与 §2「原厂 Fn+bootloader 组合键」冲突时，以该组合键为准。

### 3.1 底排（Space 右侧）约定

Space 右侧的**非方向键**，从左到右依次为 **`Alt` `Fn` `Menu` `Ctrl`**；`Menu` 仅当右侧共 **4** 个键位时存在，`Ctrl` 当右侧 **≥3** 个键位时存在：

| 右侧（非方向键）数 | 从左到右 |
| :-- | :-- |
| 2 | `Alt` `Fn` |
| 3 | `Alt` `Fn` `Ctrl` |
| 4 | `Alt` `Fn` `Menu` `Ctrl` |

- 键数**只统计非方向键**；键盘若有**原生方向键**，方向键位不动。
- 采用此约定后，绝大多数键盘**无需调整物理键位**，个别键盘仅需按上表对齐逻辑键码。
- **Mac base 同理**：其中 `Alt` 位对应 Mac 的 `Cmd`（`KC_RCMD` / `MOD_RGUI`）。

## 4. 三条规则

1. **前置条件满足** → 执行该功能；
2. **前置条件不满足** → 不执行（吞键 / 空跑，不输出任何东西）；
3. **未在约束表中声明的键（含修饰键）** → **吞键**（不输出）；唯一例外是 §2 的原厂 Fn+bootloader 组合键（最高优先级、用物理修饰键影子单独判断，不依赖 `get_mods()`）。

## 5. 约束

- **必须保留原厂 Fn + bootloader 组合键**（最高优先级，见 §2）。
- 键盘**必须把 Fn 键改成 myfn 键**（按住进入 myfn 层）。
- 键盘**只实现自己能实现的功能**；实现不了的按规则 2 处理。
- 表中“前置条件”是键盘自身的能力/状态，由键盘判断。
- **myfn 层未定义的键（含修饰键）一律吞键**（规则 3）；原厂 Fn+bootloader 组合键用**物理修饰键影子**单独识别（吞键前判断）。

## 6. 键盘实现示例

以下为通用伪代码（不含任何具体键盘名），说明约定如何落地。

```c
/* 1) 把 Fn 键改成 myfn 键：base 层该键 = MO(MYFN_LAYER) */

/* 2) myfn 层：键盘能实现的功能才放对应键，其余放 KC_NO（吞键） */

/* 3) 按住 myfn 时按三条规则处理 */
/* 维护"物理修饰键影子"：无论吞不吞键，都记录每个修饰键的物理按下/抬起，
   供最高优先级的原厂 bootloader 组合键判断（不依赖 get_mods()）。 */
bool process_record_user(uint16_t keycode, keyrecord_t *record) {
    /* 最高优先级：原厂 Fn + bootloader 组合键（见 §2），先于一切映射处理；
       用上面的物理修饰键影子判断（因修饰键随后会被吞，get_mods() 不可靠）。 */

    if (!myfn_layer_active()) {
        return true;                       /* 不在 myfn 层 → 透传 */
    }

    switch (keycode) {
        case KC_Q:                          /* 蓝牙 1 */
            if (支持蓝牙() && 挡位正确()) {
                切蓝牙(1, record->event.pressed);
            }
            return false;                   /* 前置不满足也吞键 */

        case KC_R:                          /* 2.4G */
            if (支持2.4G() && 挡位正确()) {
                切2.4G(record->event.pressed);
            }
            return false;

        case KC_T:                          /* 切有线 */
            if (无物理切换按键()) {
                切有线(record->event.pressed);
            }
            return false;                   /* 有物理开关 → 空跑 */

        case KC_L:                          /* 休眠（短按） */
            if (无物理切换按键() && !有线()) {
                进入休眠(record->event.pressed);
            }
            return false;                   /* 前置不满足也吞键 */

        /* 唤醒：Fn + 布局右上角键（仅"无物理切换按键"的键盘；睡眠中由键盘处理）；
           其它键不真正唤醒，仅瞬时唤醒后自动重回深睡 */

        case KC_SPC:                        /* 电量 */
            if (有电池()) {
                显示电量(record->event.pressed);
            }
            return false;

        case KC_CAPS:                       /* 退出 / 开关 Vim */
            if (有Vim()) {
                开关Vim(record->event.pressed);
            }
            return false;

        /* F 区（1..0 = F1..F10；- / = = F11/F12）、音量（[ / ]）、
           初始化（Esc）同理 */

        default:
            return false;                   /* 表中没有的键（含修饰键）→ 吞键（空跑） */
    }
}
```

> 说明：以上 `支持蓝牙()`、`挡位正确()`、`有电池()`…… 都是**键盘自己**的判断；
> 约定只规定“什么时候该做、什么时候不做”，不规定“怎么做”。

> **无前置的功能**（如 Fn+1..0 = F1–F10、Fn+`-`/`Fn+=` = F11/F12、Fn+`[`/`Fn+]` = 音量）
> 可直接把它们作为 **myfn 层的键码** 放在层里（QMK 正常输出），**无需任何分发代码**；只有带前置条件的功能才需要上面那种拦截。

> **原厂 Fn + bootloader 组合键**（§2）由键盘在最高优先级处保留，不属于本约束表的键位。
