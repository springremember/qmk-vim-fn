# 全面审查报告 — qmk-vim-fn 项目（2026-09-22）

> 注：本文档为项目记录（含具体键盘名 QK61/NUT65 等），仅供参考；不属于共享层（`engine/`+`qmk/`）规范。

> 审查方式：两个独立子代理（文档语义 / 技术架构）并行复审，汇总如下。
> 审查范围：`qmk-vim-fn`（文档 + 引擎）、`qmk_firmware` qk61 分支（keymap 集成）、迁移文档。
> 问题编号：`D-*` = 文档语义；`A-*` = 技术架构。处置归属标注【文档/引擎/共享 glue/键盘】。

---

## 一、总体结论

1. **引擎内核（engine/command/emit/classify）分层干净、无 QMK 渗入，状态机 pending 清理在引擎内部路径完备**；计数语义自洽度较高。
2. 风险集中在**边界**：
   - 模式/使能切换处的 pending 与 repeat 处置（D-P0-2、A-P1-1）；
   - myfn 约定的 layer 键豁免缺失（D-P0-1，曾实际卡死 layer 4）；
   - `kv_kbd` API 双头权威漂移（D-P0-3）；
   - **共享 glue 层物理上不存在**——NUT65 迁移 = 把历史 bug 全集复制一份（A-P0-1/2/3）。
3. release 配对机制存在**四套并行实现**，是 E3 类（卡键）bug 的结构性温床（A-P0-2）。

## 五、附：单键命令改用 QMK 层的可行性分析（回应「是否新增一个层省资源」）

**结论：不建议。层无法承载单键命令，且资源收益为负。**

1. **单键命令不是 1:1 键码替换**。QMK 层只能把「物理键→键码」重映射：
   - 多数单键要发**多键序列**：`s`=Shift+→+Delete+进 Insert、`o`=End+Shift+Enter、`p`=定位+Ctrl+V、`S`/`cc`=Home×2+Shift+End+…；
   - 一半以上要**切换引擎模式**（i/a/o/s/C/S/c\*/v/V 需 `kv_set_mode(INSERT/VISUAL)`）——层无法调用引擎 API。
   要发序列就得用宏/自定义键码——那仍是代码，不省。
2. **状态交互不可绕过**。引擎必须**看到**这些键码：
   - `3x`（丢计数）、`dj`/`d0`（操作符+移动）、`2d3w`（计数相乘）都依赖引擎解析同一键码；
   - 严格清空要求引擎收到非期望键并重识别（`d` 后按 `x`）；
   - 若 `h/j/k/l` 被层替换成方向键，process_record_user 收到的是 `KC_LEFT`，`dj`/`3j` 语义直接丢失。
3. **资源账不划算**。引擎 emit 表仅 ~1-2KB flash、ctx 几十字节 RAM；多键命令仍需引擎本体，层方案只省单键分支的几百字节，却引入「层切换状态 + 双路径行为漂移」的新 bug 面（正是本项目历史 bug 的同构来源）。
4. **该用层的地方已经在用**：myfn 层的 F 区/音量就是纯层键码（fn/readme §6「无前置功能直接放层键码放行」）；Insert 模式引擎直接 PASSTHROUGH 打字零开销。
5. 可选的真实优化（与层无关）：编译期裁剪不需要的命令子集（如某键盘不要缩进）；及 Insert 模式在 process_record_user 更早短路（现状已接近）。

## 七、后续修订（2026-09-26，Esc/Caps/右Shift）

本报告成文后，行为发生以下调整（实现与测试见 `qmk-vim-fn` 子模块 `2c0f45b`）：

- **Esc**：改为 Insert↔Normal 切换器。Insert（非宽限）按 Esc=吞键进 Normal；Normal 空闲按 Esc=真 Esc 回 Insert 并开 **3s 宽限**（只此一条路径开启，窗口内 Esc 重置计时）；Visual/pending 仍交引擎。引擎 `kv_kbd()` 对 Insert 一律 `KV_PASSTHROUGH`。→ 推翻本报告 D-P2-14 所处的旧语境。
- **Caps**：单击=开关 vim（开=Insert 起），长按=临时 Normal；**删除 `Fn+Caps` 特判**（等同裸 Caps）；Caps 始终被消费。→ D-P0-2/D-P2-14 中「Fn+Caps 开关 Vim」的措辞作废。
- **右 Shift**：vim 开启时孤立不发键（避免宿主输入法切换）；与它键同按临时补左 Shift（`右Shift+a`=`A`、`右Shift+Ctrl+C`=`Ctrl+Shift+C`）；`右Shift+Esc` 仍出裸 `` ` ``；vim 关闭时正常。

测试：engine 393；glue 8 套（含新增 Esc 三态/宽限、RShift 懒发送/共存）；qk61 93；nut65 203。
