# Caps 模块测试用例

> 主机侧单测：喂按键事件序列 → 观察共享 keymap 层实际注册/反注册的键与 `vim_*` 查询结果 → 断言。
> "关联"列指向 [`design.md`](design.md) 的不变量编号或 [`changes.md`](changes.md)；空白为覆盖性用例。
> Caps 模式属**键盘层行为**，由 glue 主机单测（`engine/test/glue/`）覆盖；键盘侧另有各键盘的
> `keymaps/vim/test/` 本地测试，用于确认同一份共享实现接进该键盘 cfg 后行为不变。
> **只能实机验证**：宿主观感（`Ctrl+字母`/`Ctrl+Shift+字母` 的实际效果）与厂商功能共用时的真实行为。

## 0. 覆盖范围与限制（重要）

**主机侧已可覆盖** Caps×Ctrl 交错（自 2a0c839 起）：`engine/test/glue/test_rgb.c` 的
`pipeline()` 已建模"放行即注册/反注册"，`s_mods` 是真实 mods 位图；
`test_caps_ctrl_bitmodel` 含 10 条由**变异验证**过的判别用例（退出/release 守卫、合成条件、
F 键引用计数、溢出容量与配对、非基础键码豁免、hook 可视作废等）。

**仍只能实机验证**的是**宿主语义**（非本层能决定）：
1. `Shift+Home`/`Shift+End`/`Shift+↓` 在各编辑器是否按"扩展选区/保持列"解释（行选近似的前提）；
2. `Ctrl+C`/`Ctrl+X` 得到的区间是否含行尾换行、`p` 是否粘成新行；
3. RGB 实际颜色/灯位、USB 枚举与刷写、宿主 `Ctrl+字母` 观感。

> 主机测试的绿色**可以**用于 Caps×Ctrl 交错（有变异验证）；
> **不得**用于上述宿主语义 —— 那些只能实机确认。

## 1. 进入 / 退出

| 用例 | 输入 | 期望 | 关联 |
|---|---|---|---|
| 按下即进模式 | `Caps` 按下（**不等阈值、不经 `task()`**） | 立即进入；随后按 `1` → `F1` | §3 |
| 裸 Caps 单击无效果 | `Caps` 按下 → 立即抬起（未夹键） | 撤销本次进入；vim 状态不变；无键注册 | §3 |
| Fn+Caps 开关 vim | `Fn` 先按住 + `Caps` 单击 | 切换 vim 开/关 | §3 |
| 松手退出 | 模式内按若干键 → 松开 `Caps` | 退出；vim 开关/模式不变 | §3 §4.4 |
| 退出防卡键 | 模式内**按住**某键 → 直接松开 `Caps` | 该键与 Ctrl 一并反注册 | §4.3 |
| 无孤儿 release | 模式内所有按键 | press/release 成对，不产生孤立 release | §4.5 |
| **重入清理** | 模式内按 `c`（注册 Ctrl+C）→ **再按一次 `Caps`** → 松开 `Caps` | 旧实例的 Ctrl/C 先被反注册，不残留宿主键 | §3.1-1 |
| **过期 release 过滤** | 模式前按住 `a` → 进模式 → 按 `b` → 松开 `a` | Ctrl 仍按住（`b` 未松），不提前释放 | §3.1-2 |
| **物理 Ctrl 中途松开** | 按物理 Ctrl → 进模式 → 松 Ctrl → 按 `c` | 发出 `Ctrl+C`（重新自注册 Ctrl） | §3.1-3 |
| **物理 Ctrl 中途松开（已有键按住）** | 按物理 Ctrl → 进模式 → 按 `a` → 松 Ctrl → 按 `b` | `b` 仍带 Ctrl（`a` 未松，不得以裸键发出） | §3.1-3 |
| **物理 Ctrl 按+抬（合成位保持）** | 进模式 → 按 `c`（合成 Ctrl+C）→ 按/抬物理 Ctrl → 按 `d` | `c` 未松期间合成 Ctrl 不被卸掉 | §3.1-3 |
| **层键豁免** | 模式内按 QMK 层键（`MO()` 等） | 不注册任何宿主键；press 放行（Fn 层可激活） | §3.1-4 |
| **held 表溢出** | 模式内同时按住 ≥ 表容量 个键 | 超出的键既不注册也不消费；退出后**无**残留键 | §3.1-5 |
| **孤立 release** | 无 press 的 `Caps` release | 无任何效果（不开关 vim） | §3.1-6 |

## 2. 键映射

| 用例 | 输入 | 期望 | 关联 |
|---|---|---|---|
| 数字行 → F 区 | 模式内 `1` `2` … `0` `-` `=` | 依次发出 `F1`…`F12`，且**不带 Ctrl** | §4.1 |
| F 区不按 Ctrl | 模式内任意 F 键按下期间 | Ctrl **未被注册** | §4.1 |
| 字母 → Ctrl+ | 模式内 `c` | 发出 `Ctrl+C` | §4 |
| 功能键 → Ctrl+ | 模式内 `Space` / `Enter` / `Tab` / `Backspace` | `Ctrl+Space` / `Ctrl+Enter` / `Ctrl+Tab` / `Ctrl+Backspace` | §4 |
| 修饰键 → Ctrl+修饰 | 模式内 `Shift`（→ 随后 `A`） | 按下即 `Ctrl+Shift`；组合为 `Ctrl+Shift+A` | §4.2 |
| 模式内 Esc | 模式内 `Esc` | 发 `Ctrl+Esc`；**不触发** vim 的 Esc 切换（模式不变） | §5 |

## 3. Ctrl 引用计数

| 用例 | 输入 | 期望 | 关联 |
|---|---|---|---|
| 首次按住 | 模式内第一个非 F 键按下 | Ctrl 被注册一次 | §4 |
| 重叠保持 | 模式内 `c` 按住时再按 `v` | Ctrl 保持按住（不重复注册） | §4 |
| 最后一个释放 | 松开 `v` 后再松开 `c` | 最后一个非 F 键松开时 Ctrl 释放 | §4 |
| F 键不干扰计数 | 模式内交替按 F 键与非 F 键 | 计数只由非 F 键改变 | §4.1 |
| 物理 Ctrl 已在按住 | 进入模式前已按物理 Ctrl | 不重复注册；退出也不反注册该物理 Ctrl | §2 |

## 4. 与 vim / pipeline 的关系

| 用例 | 输入 | 期望 | 关联 |
|---|---|---|---|
| vim 关闭可用 | vim 关（红灯）时按下 `Caps` | 同样按上表映射 | readme §1 |
| 模式不改 vim | 进入前后查询 `vim_*` | 开关与模式完全一致 | §4.4 |
| 模式内键不进引擎 | 模式内按 `d`（Normal 下的操作符） | 只发 `Ctrl+D`，**不产生** pending | §5 |
| 拦截优先 | 模式内按 myfn 已声明键 | 由本模块接管，不进入 myfn 分发 | §5 |
