# Caps 模块测试用例

> 主机侧单测：喂按键事件序列 → 观察共享 keymap 层实际注册/反注册的键与 `vim_*` 查询结果 → 断言。
> "关联"列指向 [`design.md`](design.md) 的不变量编号或 [`changes.md`](changes.md)；空白为覆盖性用例。
> Caps 模式属**键盘层行为**，由 glue 主机单测（`engine/test/glue/`）覆盖；键盘侧另有各键盘的
> `keymaps/vim/test/` 本地测试，用于确认同一份共享实现接进该键盘 cfg 后行为不变。
> **只能实机验证**：宿主观感（`Ctrl+字母`/`Ctrl+Shift+字母` 的实际效果）与厂商功能共用时的真实行为。

## 1. 进入 / 退出

| 用例 | 输入 | 期望 | 关联 |
|---|---|---|---|
| 短按不进模式 | `Caps` 按下 → < `hold_ms` 抬起 | 不进入模式；短按语义不变；未注册 Ctrl | §3 |
| 长按进模式 | `Caps` 按下 → ≥ `hold_ms`（判定在 `task()`） | 进入模式；**vim 开关与模式不变** | §3 |
| 边界：恰好 `hold_ms` | `Caps` 按下 → +`hold_ms` → 释放 | 视为长按（进入过模式后退出） | §3 |
| 边界：`hold_ms - 1` | `Caps` 按下 → +`hold_ms-1` → 释放 | 视为短按 | §3 |
| 松手退出 | 模式内按若干键 → 松开 `Caps` | 退出；vim 开关/模式不变 | §3 §4.4 |
| 退出防卡键 | 模式内**按住**某键 → 直接松开 `Caps` | 该键与 Ctrl 一并反注册 | §4.3 |
| 无孤儿 release | 模式内所有按键 | press/release 成对，不产生孤立 release | §4.5 |

## 2. 键映射

| 用例 | 输入 | 期望 | 关联 |
|---|---|---|---|
| 数字行 → F 区 | 模式内 `1` `2` … `0` `-` `=` | 依次发出 `F1`…`F12`，且**不带 Ctrl** | §4.1 |
| F 区不按 Ctrl | 模式内任意 F 键按下期间 | Ctrl **未被注册** | §4.1 |
| 字母 → Ctrl+ | 模式内 `c` | 发出 `Ctrl+C` | §4 |
| 功能键 → Ctrl+ | 模式内 `Space` / `Enter` / `Tab` / `Backspace` | `Ctrl+Space` / `Ctrl+Enter` / `Ctrl+Tab` / `Ctrl+Backspace` | §4 |
| 修饰键 → Ctrl+修饰 | 模式内 `Shift`（→ 随后 `A`） | 按下即 `Ctrl+Shift`；组合为 `Ctrl+Shift+A` | §4.2 |
| 模式内 Esc | 模式内 `Esc` | 发 `Ctrl+Esc`；**不触发** vim 的 Esc 切换（模式不变） | §5 |

## 3. Ctrl 引用计数

| 用例 | 输入 | 期望 | 关联 |
|---|---|---|---|
| 首次按住 | 模式内第一个非 F 键按下 | Ctrl 被注册一次 | §4 |
| 重叠保持 | 模式内 `c` 按住时再按 `v` | Ctrl 保持按住（不重复注册） | §4 |
| 最后一个释放 | 松开 `v` 后再松开 `c` | 最后一个非 F 键松开时 Ctrl 释放 | §4 |
| F 键不干扰计数 | 模式内交替按 F 键与非 F 键 | 计数只由非 F 键改变 | §4.1 |
| 物理 Ctrl 已在按住 | 进入模式前已按物理 Ctrl | 不重复注册；退出也不反注册该物理 Ctrl | §2 |

## 4. 与 vim / pipeline 的关系

| 用例 | 输入 | 期望 | 关联 |
|---|---|---|---|
| vim 关闭可用 | vim 关（红灯）时长按 `Caps` | 同样按上表映射 | readme §1 |
| 模式不改 vim | 进入前后查询 `vim_*` | 开关与模式完全一致 | §4.4 |
| 模式内键不进引擎 | 模式内按 `d`（Normal 下的操作符） | 只发 `Ctrl+D`，**不产生** pending | §5 |
| 拦截优先 | 模式内按 myfn 已声明键 | 由本模块接管，不进入 myfn 分发 | §5 |
