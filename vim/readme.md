# vim 模式使用说明

> 面向使用。描述 vim 引擎的**目标行为**（键盘无关）。技术细节见 [`design.md`](design.md)。
> 引擎以**纯键码**工作：把 vim 命令翻译成宿主按键序列发送，不依赖编辑器插件。
> 文末与前文出现的键盘名（如 QK61/NUT65）仅为**参考示例**；本仓库共享层不含任何键盘专属实现或测试。
> 键盘**开机默认进入 Insert（照常打字）**；按 `Esc` 或单击 `Caps` 切换 vim 开关。

---

## 1. 模式与切换

| 模式 | 作用 |
|---|---|
| Insert | 普通打字（默认） |
| Normal | 执行 vim 命令 |
| Visual | 选区（字符） |
| Visual-Line | 选区（整行） |

| 操作 | 效果 |
|---|---|
| `Esc`（Insert，非宽限） | **进入 Normal（不发送 Esc）** |
| `Esc`（Insert，3s 宽限内） | 发送真实 `Esc`，留在 Insert，并**重置 3s 宽限** |
| `Esc`（Normal 空闲） | 发送真实 `Esc`，**进入 Insert**，并**开启 3s 宽限** |
| `Esc`（Visual/Visual-Line） | 退出选区回 Normal（不发送 Esc） |
| `Caps` 单击 | **切换 vim 开/关**（开=从 Insert 起；关=禁用 vim）|
| `Caps` 长按（≥200ms） | 临时进入 Normal，松手回到原模式 |
| `Fn+Caps` | 与裸 `Caps` **完全相同**（无特殊处理）|

> **Esc 宽限（3s）**：只由「Normal 空闲按 Esc 回到 Insert」这一条路径开启，且窗口内再按 `Esc` 会重置计时。
> 用途：连续按 Esc（如从 shell 提示符退出、多次退出全屏）仍是真实 Esc；其余进入 Insert 的路径
> （开机、`Caps` 开启 vim、`i/I/a/A/o/O`、`s/c`）**没有宽限**，其后的 Insert `Esc` 一律进 Normal。
> `Caps` 单击**不再进入 Normal**，它只开关 vim；进入 Normal 现由 `Esc`（或 `Caps` 长按）负责。
> 多键 pending（如按了 `d`）时按 `Esc`：**仅取消 pending，不发送任何键**（不变）。
> **任何模式切换都会丢弃未完成的多键命令**（计数/操作符/`g`/`Z` 前缀）：如 `d` 后切模式，
> 回 Normal 按 `w` 只会执行 `w`，不会残留成 `dw`。

> **右 `Shift`（仅 vim 开启时）**：为避免孤立 Shift 触发宿主输入法切换，右 `Shift` **单独按下/抬起不发送
> 任何东西**；当它按住期间有别的键时才**临时补上左 Shift**（`右Shift+a` = `A`，`右Shift+Ctrl+C` =
> `Ctrl+Shift+C`），松开右 Shift 即撤下。vim 关闭时右 `Shift` 与普通修饰键无异。

## 2. 移动（Normal / Visual）

| 键 | 动作 | 宿主按键 |
|---|---|---|
| `h` `j` `k` `l` | 左 / 下 / 上 / 右 | `←` `↓` `↑` `→`（**可按住连续移动**） |
| `w` `W` | 下一个词首 | `Ctrl+→` |
| `b` `B` | 上一个词首 | `Ctrl+←` |
| `e` `E` | 下一个词尾 | `Ctrl+→`（近似） |
| `0` `^` | 行首 | `Home` |
| `$` | 行尾 | `End` |
| `G` | 文档末 | `Ctrl+End` |
| `gg` | 文档首 | `Ctrl+Home` |

> `e`/`E` 与 `w` 在键注入下近似相同（宿主词跳只能到词首）。

---

## 3. 编辑（Normal）

| 键 | 动作 |
|---|---|
| `x` | 删除光标处字符（`Delete`） |
| `s` | 修改字符：选中右一字符（`Shift+→`）后 change 并进入 Insert |
| `X` | 删除光标前一字符（`Backspace`） |
| `S` | 修改整行（`cc`） |
| `C` | 修改到行尾（`c$`，进入 Insert） |
| `D` | 删除到行尾（`d$`） |
| `Y` | 复制到行尾（`y$`） |
| `p` / `P` | 粘贴（`Ctrl+V`）。按 `yanked_line` 定位：`yanked_line` 时 `p` 先 `End+→`、`P` 先 `End+→+↑`；否则 `P` 先 `←` |
| `J` | 合并下一行（`End` + `Delete`） |
| `u` | 撤销（`Ctrl+Z`，单次） |
| `.` | 重复上一个编辑命令 |

### 3.1 操作符 + 动作

操作符 `d`（删）`y`（复制）`c`（改）后接一个移动：

```
d w     删除到下一词首
d $     删除到行尾
d 0     删除到行首
d G     删除到文档末
y e     复制到词尾
c w     改到下一词首（进入 Insert）
```

### 3.2 行操作（操作符自叠）

| 命令 | 动作 |
|---|---|
| `dd` / `Ndd` | 删除（N 行） |
| `yy` / `Nyy` | 复制（N 行） |
| `cc` / `Ncc` | 修改整行（N 行） |

> `dd` 说明：可删除文档**末行**；代价是**首行会留一个空行**，且 `dd` 是两次宿主编辑，
> 因此按一次 `u` **只恢复一半**，需要再按一次 `u` 才完全恢复。

### 3.3 缩进

| 命令 | 动作 |
|---|---|
| `>` / `<` + 移动 | 缩进 / 反缩进（到移动范围） |
| `>>` / `<<` | 当前（或 N 行）缩进 / 反缩进 |

---

## 4. 插入（Normal → Insert）

| 键 | 动作 |
|---|---|
| `i` | 在光标处进入 Insert |
| `I` | 行首（`Home`）后进入 Insert |
| `a` | 光标右侧进入 Insert |
| `A` | 行尾（`End`）后进入 Insert |
| `o` | 下方新起一行并进入 Insert（`End` + `Shift+Enter`） |
| `O` | 上方新起一行并进入 Insert（`Home` + `Shift+Enter` + `↑`） |

> 换行统一用 `Shift+Enter`（部分编辑器 `Enter` 行为不一致）。

---

## 5. 计数

- 数字为**前缀**：如 `3w`、`5j`、`12j`（最多 2 位）。
- 操作符前后可各带计数，**相乘**：`2d3w` = `d6w`（删除 6 个词）。
- 计数**只作用于移动、缩进与行操作**（含 `cc`/`S`）。
- **丢弃计数**（计数被吸收但不生效，命令按无计数执行一次）：`G`/`gg`（**移动的例外，任何上下文**）、`C D Y X`、`x s p P J u .`、`v V`、插入键、`ZZ`。例：`3G`≡`G`、`3D`≡`D`、`3x`≡`x`、`2dG`≡`dG`、`2dgg`≡`dgg`。
- `S` ≡ `cc`，**接受计数**（`3S` = 改 3 行）。
- 计数**最多 2 位（≤99）**，第 3 位起忽略（`123w`≡`12w`）。
- **首位不能是 `0`**（`0` 是"行首"命令）；`10w` 合法。
- `dw3` 中的 `3` 不是被忽略，而是**新的计数前缀**，等待下一个命令。

## 6. 前缀键

| 键 | 后接 | 结果 |
|---|---|---|
| `g` | `g` | `gg`（文档首） |
| `Z` | `Z` | `ZZ`（保存） |

`g`/`Z` 只有唯一后续键；按到其它键则**清空前缀并把该键当新命令重新识别**（非 vim 键则原样透传）。

---

## 7. Visual / Visual-Line

| 操作 | 效果 |
|---|---|
| `v` / `V` | 进入 Visual / Visual-Line |
| 移动键（可带计数，如 `3l`） | 扩展选区 |
| `d` / `x` | 删除选区（`Ctrl+X`） |
| `y` | 复制选区（`Ctrl+C`） |
| `c` / `s` | 修改选区（`Ctrl+X`，进入 Insert） |
| `p` | 粘贴覆盖选区 |
| `Esc` | 退出选区回 Normal |

> 未列出的键（如 `i`/`a`、数字、`g`/`Z`、`<`/`>`）在 Visual 内为**非法键**：保持在 Visual
> （吞键，不退出、不插入、**不产生 pending**）；这不是"非 vim 键透传"规则（`i`/`a` 属 vim 键码集）。
> 操作完成后（`d/y/c/p` 等）自动回到 Normal。

## 8. 鼠标模式（键盘层）

由**右 `Alt` 短按切换**（`Insert` / `Normal` / `Visual` **均可**进出）；退出后回到进入前的模式。

- **短按**右 `Alt` = 进/出鼠标模式（不输出键）；
- **长按**右 `Alt` = 作为普通 `RAlt` 修饰键（阈值 200ms，与 `Caps` 一致）。

| 键 | 行为 |
|---|---|
| `h` `j` `k` `l` | 指针 左/下/上/右（`←` `↓` `↑` `→`） |
| `Shift+J` | 滚轮向下 |
| `Shift+K` | 滚轮向上 |
| `Space` | 左键：短按单击、长按（≥200ms）拖动 |
| `Enter` | 右键 |
| `Shift`（左/右） | **不退出**鼠标模式（press 吞；在鼠标内按下的 release 由配对表吞掉，进入鼠标前已按住的 Shift 则透传，供 `Shift+J`/`Shift+K` 滚轮组合） |
| `Ctrl` / `Alt` / `Gui`（左/右） | **按下即退出**鼠标模式（自动松开所有鼠标键/指针/滚轮），回原模式并**重新识别该修饰键**（其 release 随后正常透传） |
| **其它任意非修饰键** | 立即退出鼠标模式（**自动松开**所有按住的鼠标键/指针/滚轮），回原模式并**重新识别该键码** |

## 9. 键盘层交互（键盘层实现）

| 键 | Normal 下行为 |
|---|---|
| `Backspace` | 左移（`←`） |
| `Space` | 右移（`→`） |
| `-` | 上一行行首（`Up` + `Home`） |
| `Shift+=` | 下一行行首（`Down` + `Home`） |
| `Ctrl+F` / `Ctrl+B` | 下翻页 / 上翻页（`PgDn` / `PgUp`） |
| `/` | 调用宿主查找（`Ctrl+F`） |
| `Enter` / `Tab` | 透传真实按键 |
| `Shift+Esc`（**仅 Insert**） | 左 `Shift`=`~`、右 `Shift`=`` ` ``（右 Shift 剥离，不发 Shift） |

> 这些是 keymap 层行为，不同键盘可自行取舍。
> **Normal 下按住 `Ctrl`/`Alt`/`GUI`（Win/Cmd）时**：普通键组合原样透传宿主（如 `Ctrl+C`）；
> **仅 `h/j/k/l` 例外**——仍作方向键，并与该修饰键组合（如 `Win+h` 发 `Win+←`），不把裸 `h` 透传。
> **消费 press 的组合键，其 release 也须一并消费**：如 `Shift+Esc` 按下时改发 `~`/`` ` `` 后，其**抬起必须吞掉**（记住已消费的键、无条件吞），否则会多打出一个键。
> **右 `Shift`**（仅 vim 开启）：单独不发送；与其它键同按才临时补左 Shift（`右Shift+a`=`A`、`右Shift+Ctrl+C`=`Ctrl+Shift+C`）。

## 10. 状态指示（RGB，键盘层）

| 状态 | 颜色 |
|---|---|
| Insert | 绿 |
| Normal（空闲） | 蓝 |
| Normal 多键 pending（计数/操作符/缩进/`g`/`Z` 待结束） | 黄 |
| Visual / Visual-Line | 紫（Visual **没有**多键 pending：非法键直接吞键，因此不显示黄） |
| 鼠标模式 | 青（cyan） |
| vim 关闭 | 红 |

> pending 黄**不覆盖** Visual / Visual-Line：Visual 内做多键时仍显示紫。

## 11. 不提供的功能

出于"纯键码、键盘无关"的限制，以下**不提供**：

- 文本对象（`iw`/`aw`/`i"` 等）——需要识别文本边界；
- 搜索 / 查找 / 标记（`/ ? n N f t * # %`、`m`、反引号/单引号跳转等）——需要读文本；
- `@` 宏 / 寄存器 / `"` 前缀 / `Ctrl+R` 带寄存器；
- 窗口命令、命令行 `:`；
- 替换模式 `R`；`NG`（跳转第 N 行）；
- 段落移动 `{}`、屏幕行 `gj/gk/gJ`。

原因：键盘只能发送键码，无法读取/判断编辑器缓冲区内容；上述命令要么需要读文本，
要么依赖具体编辑器行为。其余**非 vim 键码**一律原样透传。

> 注：引擎**禁用阻塞式 `wait_ms`**（emit 走非阻塞队列）；仅键盘层的保命流程（如原厂 bootloader 组合键）可例外使用 `wait_ms`。
