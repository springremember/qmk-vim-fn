# vim 模式使用说明

> 面向使用。描述 vim 引擎的**目标行为**（键盘无关）。技术细节见 [`design.md`](design.md)。
> 引擎以**纯键码**工作：把 vim 命令翻译成宿主按键序列发送，不依赖编辑器插件。
> 文末与前文出现的键盘名（如 QK61/NUT65）仅为**参考示例**；本仓库共享层不含任何键盘专属实现或测试。
> 键盘**开机默认进入 Insert（照常打字）**；按 `Esc` 在 Insert/Normal 间切换；`Fn`+`Caps` 单击开关 vim。

---

## 1. 模式与切换

| 模式 | 作用 |
|---|---|
| Insert | 普通打字（默认） |
| Normal | 执行 vim 命令 |
| Visual | 选区（字符） |
| Visual-Line | 选区（整行） |

| 操作 | 效果 |
|---|---|
| `Esc`（Insert，非宽限） | **进入 Normal（不发送 Esc）** |
| `Esc`（Insert，3s 宽限内） | 发送真实 `Esc`，留在 Insert，并**重置 3s 宽限** |
| `Esc`（Normal 空闲） | 发送真实 `Esc`，**进入 Insert**，并**开启 3s 宽限** |
| `Esc`（Visual/Visual-Line） | 退出选区回 Normal（不发送 Esc） |
| `Fn` + `Caps` 单击 | **切换 vim 开/关**（开=从 Insert 起；关=禁用 vim；`Fn` 先按住）|
| `Caps` 单击（裸按） | **无任何效果**（不开关 vim，也不进入 Normal）|
| `Caps` 长按 | **按下即进入 Caps 模式**（`1`–`0`/`-`/`=`=`F1`–`F12`，其余键=`Ctrl+键`），松开退出（见 §9）|

> **Esc 宽限（3s）**：只由「Normal 空闲按 Esc 回到 Insert」这一条路径开启，且窗口内再按 `Esc` 会重置计时。
> 用途：连续按 Esc（如从 shell 提示符退出、多次退出全屏）仍是真实 Esc；其余进入 Insert 的路径
> （开机、`Caps` 开启 vim、`i/I/a/A/o/O`、`s/c`）**没有宽限**，其后的 Insert `Esc` 一律进 Normal。
> 进入 Normal **只由 `Esc` 负责**（`Caps` 长按是 Caps 模式，见 §9）；
> **vim 开关的唯一键盘入口是 `Fn` + `Caps`**（裸 `Caps` 单击无效果，避免误触）。
> 记为 `Fn`+`Caps` 开启 vim 的路径同样不亮橙。
> 多键 pending（如按了 `d`）时按 `Esc`：**仅取消 pending，不发送任何键**（不变）。
> **任何模式切换都会丢弃未完成的多键命令**（计数/操作符/`g`/`Z` 前缀）：如 `d` 后切模式，
> 回 Normal 按 `w` 只会执行 `w`，不会残留成 `dw`。

> **右 `Shift`（仅 vim 开启时）**：为避免孤立 Shift 触发宿主输入法切换，右 `Shift` **单独按下/抬起不发送
> 任何东西**；当它按住期间有别的键时才**临时补上左 Shift**（`右Shift+a` = `A`，`右Shift+Ctrl+C` =
> `Ctrl+Shift+C`），松开右 Shift 即撤下。vim 关闭时右 `Shift` 与普通修饰键无异。

## 2. 移动（Normal / Visual）

| 键 | 动作 | 宿主按键 |
|---|---|---|
| `h` `j` `k` `l` | 左 / 下 / 上 / 右 | `←` `↓` `↑` `→`（**可按住连续移动**） |
| `w` `W` | 下一个词首 | `Ctrl+→` |
| `b` `B` | 上一个词首 | `Ctrl+←` |
| `e` `E` | 下一个词尾 | `Ctrl+→`（近似） |
| `0` `^` | 行首 | `Home` |
| `$` | 行尾 | `End` |
| `G` | 文档末 | `Ctrl+End` |
| `gg` | 文档首 | `Ctrl+Home` |

> `e`/`E` 与 `w` 在键注入下近似相同（宿主词跳只能到词首）。

## 3. 编辑（Normal）

| 键 | 动作 |
|---|---|
| `x` | 删除光标处字符（发 `Shift+→` 选中后 `Ctrl+X`，**写无名寄存器**，`xp` 才能交换字符） |
| `s` | 修改字符：`Shift+→` + `Ctrl+X` 后进入 Insert（真实 Vim `s` ≡ `cl`） |
| `X` | 删除光标前一字符（`Shift+←` + `Ctrl+C` + `Backspace`；**不用**剪切，避免列 0 空选区被当成"剪切整行"） |
| `S` | 修改整行（≡ `cc`：留一个空行、寄存器为**行级**，进入 Insert） |
| `C` | 修改到行尾（`c$`，进入 Insert） |
| `D` | 删除到行尾（`d$`） |
| `Y` | **行级复制（≡ `yy`）**，不是 `y$` |
| `p` / `P` | 粘贴（`Ctrl+V`），**按无名寄存器类型定位**：字符级 `p` = 光标字符**之后**（先 `→`）、`P` = 光标字符**之前**（直接粘）；行级 `p` = **下一行新建一行**（先 `End,→`）、`P` = 当前位置。类型由最近一次写剪贴板的命令跟踪（`dd`/`yy`/`Y`/行选/`dj`… 行级；`x`/`X`/`s`/`dw`/`yl`… 字符级） |
| `J` | 合并下一行（`End` + `Space` + `Delete` + `←`，插一个空格并把光标留在那个空格上）。**不**去掉下一行的前导空白（Vim 会去掉） |
| `u` | 撤销（`Ctrl+Z` **单次**）；带计数时 `Nu` 撤销 N 次 |
| `.` | 重复上一个**编辑（修改缓冲区）**命令 |

> **`.` 的目标是「上一次修改」**（真实 Vim 语义）：只有改缓冲区的命令会成为 `.` 的目标 ——
> 操作符 `d`/`c` + 动作、`x X s C D p P J S`、缩进 `>> <<`；**裸移动**（`h j k l w b e 0 ^ $ gg G`
> 及带计数的移动）与**纯复制** `y`/`Y` 都**不**改变 `.` 的目标。所以 `dw` → `w` → `.` 仍然重复
> `dw`；只按过移动时 `.` 无动作。**`N.` 重复 N 次**（`dw` 后 `3.` 连删 3 个词；总键码数按
> 队列容量封顶在 99）。已知限制：插入（`i a o …`）键入的文本固件记录不到，故 `.` **不会**
> 重复插入内容；`. ` 在 Visual 内是非法键（吞键留在 Visual）。

### 3.1 操作符 + 动作

操作符 `d`（删）`y`（复制）`c`（改）后接一个移动：

```
d w     删除到下一词首
d $     删除到行尾
d 0     删除到行首
d G     删除到文档末
y e     复制到词尾
c w     改到下一词首（进入 Insert）
```

### 3.2 行操作（操作符自叠）

| 命令 | 动作 |
|---|---|
| `dd` / `Ndd` | 删除（N 行） |
| `yy` / `Nyy` | 复制（N 行）—— 复制后补 `Esc` 取消宿主残留选区，否则下一个键会替换刚复制的内容 |
| `cc` / `Ncc` | 修改整行（N 行）—— **留一个空行**后进 Insert（与 Vim 一致） |

> `dd` 说明：**可删除文档末行**，**首行也不留空行**（`Shift+End` 后补 `Shift+→` 把行尾换行纳入
> 半开选区），且整条命令是**一次宿主编辑**（一个 `Ctrl+X`）——因此按一次 `u` 即**完整恢复**
> （实测 `ddu` 的缓冲区与寄存器均与真实 Vim 一致）。
> `cc`/`S` 与 `dd` **不同**：它按 Vim 语义**留一个空行**（`Ctrl+X` 后补 `Shift+Enter,←`），
> 三种行位置都正确，且无名寄存器是**行级**（含换行）。

### 3.3 缩进

| 命令 | 动作 |
|---|---|
| `>` / `<` + 移动 | 缩进 / 反缩进（到移动范围） |
| `>>` / `<<` | 当前（或 N 行）缩进 / 反缩进 |

## 4. 插入（Normal → Insert）

| 键 | 动作 |
|---|---|
| `i` | 在光标处进入 Insert |
| `I` | 行首（`Home`）后进入 Insert |
| `a` | 光标右侧进入 Insert |
| `A` | 行尾（`End`）后进入 Insert |
| `o` | 下方新起一行并进入 Insert（`End` + `Shift+Enter`） |
| `O` | 上方新起一行并进入 Insert（`Home` + `Shift+Enter` + `↑`） |

> 换行统一用 `Shift+Enter`（部分编辑器 `Enter` 行为不一致）。

## 5. 计数

计数作用于：**移动**、**行操作**（`Ndd`/`Nyy`/`Ncc`）、**缩进**（`N>>`）、
**单键编辑**（`Nx`/`NX`/`Ns`/`NJ`/`Np`/`NP`/`Nu`/`N.`）以及 `NC`/`ND`/`NY`
（`NC`/`ND` 作用到下面第 N-1 行的行尾；`NY` ≡ `Nyy`，行级）。仍**丢弃**计数：
`G`/`gg`/`ZZ`/插入键 `i I a A o O`/`v V`。

- 数字为**前缀**：如 `3w`、`5j`、`12j`（最多 2 位）。
- 操作符前后可各带计数，**相乘**：`2d3w` = `d6w`（删除 6 个词）。
- **丢弃计数**（计数被吸收但不生效，命令按无计数执行一次）：`G`/`gg`（**移动的例外，任何上下文**）、
  `ZZ`、插入键 `i I a A o O`、`v`/`V`。例：`3G`≡`G`、`2dG`≡`dG`、`2dgg`≡`dgg`。
- **接受计数**（与单键编辑并列）：`x`/`X`/`s`/`J`/`p`/`P`/`u`/`.`/`C`/`D`/`Y` —— 例：`3x` 删 3 个字符、
  `3p` 粘 3 次、`3J` 连 3 行、`3u` 撤销 3 次、`3D` 删到下面第 2 行的行尾。
- `S` ≡ `cc`，**接受计数**（`3S` = 改 3 行）。
- 计数**最多 2 位（≤99）**，第 3 位起忽略（`123w`≡`12w`）。
- **首位不能是 `0`**（`0` 是"行首"命令）；`10w` 合法。
- `dw3` 中的 `3` 不是被忽略，而是**新的计数前缀**，等待下一个命令。

## 6. 前缀键

| 键 | 后接 | 结果 |
|---|---|---|
| `g` | `g` | `gg`（文档首） |
| `Z` | `Z` | `ZZ`（保存） |

`g`/`Z` 只有唯一后续键；按到其它键则**清空前缀并把该键当新命令重新识别**（非 vim 键则原样透传）。

## 7. Visual / Visual-Line

| 操作 | 效果 |
|---|---|
| `v` | 进入 Visual（字符级） |
| `V` | 进入 **Visual-Line（行选）**：进入即选中**整行**（`Home` → `Shift+End`），移动按**整行**扩展 |
| 移动键（可带计数，如 `3l`） | 扩展选区；**两模式的移动输出不同**，见下表 |
| `d` / `x` | 删除选区（`Ctrl+X`，直接作用于当前选区） |
| `y` | 复制选区（`Ctrl+C`，随后补 `Esc` 取消宿主残留选区） |
| `c` / `s` | 修改选区（`Ctrl+X`，进入 Insert） |
| `p` | 粘贴覆盖选区 |
| `Esc` | 退出选区回 Normal |

**Visual-Line（`V`）的行选映射**（与 Visual 的差异即在这张表；纯键码下靠引擎自记行偏移**重建**整行选区）：

| 键 | Visual（字符级） | Visual-Line（行选） |
|---|---|---|
| `j` / `k` | `Shift+↓` / `Shift+↑` | `Shift+↓` / `Shift+↑`（整行扩展；方向翻转时先重锚） |
| `w` / `e` | `Ctrl+Shift+→` | **`Shift+↓`**（下一行，Vim 词动作的整行近似） |
| `b` | `Ctrl+Shift+←` | **`Shift+↑`**（上一行） |
| `0` / `^` / `$` | `Shift+Home` / `Shift+End` | **不发键**（行范围不变，与 Vim 一致） |
| `h` / `l` | `Shift+←/→` | **不发键**（同上；旧版会跨行，已废弃） |
| `gg` / `G` | `Ctrl+Shift+Home/End` | `Ctrl+Shift+Home/End`（文首/文末；方向态不同时先重锚） |
| `v` / `V` | `V` 切到行选 | `v` 切回字符选 |

> **动作按行、与方向无关**：`y`/`d`/`x`/`c`/`s` 先保证字符选区覆盖**整行**（DOWN 态补一次 `Shift+Right`
> 把行尾换行纳入），因此 `V y` 得到的是 **linewise 寄存器**（含 `\n`），`V j y` / `V k y` / `V gg y`
> 都复制**完整多行**；`V d` 真正**删掉整行**（不是只清正文留空行）。
> `V c` 与 `V s` **完全等价**：删掉整行、留一个空行、进 Insert（真实 Vim 亦然）。
> `y`/`p` 后补发 `Esc` 取消宿主残留选区，避免下一个按键替换刚复制的内容。

> **已知偏差**：`w`/`e`/`b` 按整行近似（Vim 是**词**动作）；动作后光标停在活动端（Vim 停在选区首行）；
> 末行无换行时 `V d` 留一个空行、`V y` 的寄存器少一个换行；**`G`/`gg` 之后再反向越过锚行会出错**
> （`off` 已丢失、无法重锚；`d`/`x` 会删错范围 —— 请避免该序列）；`V y` 后按 `p` 只发 `Ctrl+V`
> （不做「下一行新建粘贴」）；**行选跨度上限 100 行**（发送队列只有 256 格，重锚/`gg`/`G` 是
> O(|off|) 键码；到上限后同向移动不再扩展，而不是丢键错乱）；`3G`/`3gg` 的计数被丢弃；可视 `p`
> 不更新宿主剪贴板；`V` 后按 `v` 切字符选时宿主选区仍是整行。

> **计数**（`3j`、`2w` 等）在两种可视模式都生效：数字先累积，随后**一个移动键**按计数重复
> （`3j` = 连续 3 次推进）；最多 2 位（同 Normal）。数字累积期间**不产生多键 pending**
> （Visual 下 `pending` 恒为 false），按 `Esc` 退出可视会丢弃未消费的计数。
> `d`/`y`/`c`/`s`/`p`/`Esc` 在两模式下相同（对当前选区生效）；**动作后退出可视**：
> `y` = 复制后回 Normal，`d`/`x` = 删除后回 Normal，`c`/`s` = 剪+进 Insert，`p` = 粘贴后回 Normal。

> 未列出的键（如 `i`/`a`、数字、`Z`、`<`/`>`）在 Visual 内为**非法键**：保持在 Visual
> （吞键，不退出、不插入、**不产生 pending**）；这不是"非 vim 键透传"规则（`i`/`a` 属 vim 键码集）。
> 操作完成后（`d/y/c/p` 等）自动回到 Normal。

## 8. 鼠标模式（键盘层）

由**右 `Alt` 短按切换**（`Insert` / `Normal` / `Visual` **均可**进出）；退出后回到进入前的模式。

- **短按**右 `Alt` = 进/出鼠标模式（不输出键）；
- **长按**右 `Alt` = 作为普通 `RAlt` 修饰键（阈值 200ms）。

| 键 | 行为 |
|---|---|
| `h` `j` `k` `l` | 指针 左/下/上/右（`←` `↓` `↑` `→`） |
| `Shift+J` | 滚轮向下 |
| `Shift+K` | 滚轮向上 |
| `Space` | 左键：短按单击、长按（≥200ms）拖动 |
| `Enter` | 右键 |
| `Shift`（左/右） | **不退出**鼠标模式（press 吞；在鼠标内按下的 release 由配对表吞掉，进入鼠标前已按住的 Shift 则透传，供 `Shift+J`/`Shift+K` 滚轮组合） |
| `Ctrl` / `Alt` / `Gui`（左/右） | **按下即退出**鼠标模式（自动松开所有鼠标键/指针/滚轮），回原模式并**重新识别该修饰键**（其 release 随后正常透传） |
| **其它任意非修饰键** | 立即退出鼠标模式（**自动松开**所有按住的鼠标键/指针/滚轮），回原模式并**重新识别该键码** |

---

## 9. Caps 长按模式（Caps mode）

**按下 `Caps` 立即进入**（**不等** 200ms）：`1`–`0`/`-`/`=` = `F1`–`F12`（**不带 Ctrl**），
**其余全部键** = `Ctrl+该键`（修饰键即 `Ctrl+Shift`）；**松开 `Caps` 退出**（momentary），
退出时反注册本模式发出过的所有键与 Ctrl（防卡键）。模式内按键**不经过 vim 引擎**，
vim 开关/模式完全不变，vim 关闭时同样可用；模式内 `Esc` 发 `Ctrl+Esc`（不触发 Esc 切换）。

| 操作 | 效果 |
| :--- | :--- |
| `Caps` 按下 | 立即进入 Caps 模式（随之按下的键按本模式映射） |
| 按下期间**未按其它键**就抬起 | 撤销本次进入（不误发键、不改 vim 状态） |
| `Caps` 单击（裸按） | **无任何效果** |
| `Fn` + `Caps` 单击 | **切换 vim 开/关**（`Fn` 先按住） |

> 完整规格与用例见共享层 [`caps/readme.md`](../caps/readme.md)、[`caps/design.md`](../caps/design.md)、
> [`caps/testcase.md`](../caps/testcase.md)。别名冲突自担：`Ctrl+M`=Enter、`Ctrl+I`=Tab、
> `Ctrl+H`=Backspace、`Ctrl+[`=Esc。

## 9b. 鼠标模式（键盘层实现）

| 键 | Normal 下行为 |
|---|---|
| `Backspace` | 左移（`←`） |
| `Space` | 右移（`→`） |
| `-` | 上一行行首（`Up` + `Home`） |
| `Shift+=` | 下一行行首（`Down` + `Home`） |
| `Ctrl+F` / `Ctrl+B` | 下翻页 / 上翻页（`PgDn` / `PgUp`） |
| `/` | 调用宿主查找（`Ctrl+F`） |
| `Enter` / `Tab` | 透传真实按键 |
| `Shift+Esc`（**仅 Insert**） | 左 `Shift`=`~`、右 `Shift`=`` ` ``（右 Shift 剥离，不发 Shift） |
| `Esc`（Insert ↔ Normal 切换） | `Insert` 按 `Esc` → 吞键进 `Normal`（不发 Esc）；`Normal` 空闲按 `Esc` → 发真实 `Esc` 回 `Insert`，并开启 **3s 宽限窗口**（窗口内再按 `Esc` 仍是真实 `Esc`，不切回 Normal；窗口过期后 `Esc` 恢复切换语义） |

> 这些是 keymap 层行为，不同键盘可自行取舍。
> **`Esc` 宽限窗口的一个可见副作用**：`Normal --Esc--> Insert` 后 3s 内，模式指示色由 Insert 绿替换为
> 键盘配置的提示色（见 §10「回到打字提示」）。
> **Normal 下按住 `Ctrl`/`Alt`/`GUI`（Win/Cmd）时**：普通键组合原样透传宿主（如 `Ctrl+C`）；
> **仅 `h/j/k/l` 例外**——仍作方向键，并与该修饰键组合（如 `Win+h` 发 `Win+←`），不把裸 `h` 透传。
> **消费 press 的组合键，其 release 也须一并消费**：如 `Shift+Esc` 按下时改发 `~`/`` ` `` 后，其**抬起必须吞掉**（记住已消费的键、无条件吞），否则会多打出一个键。
> **右 `Shift`**（仅 vim 开启）：单独不发送；与其它键同按才临时补左 Shift（`右Shift+a`=`A`、`右Shift+Ctrl+C`=`Ctrl+Shift+C`）。

## 10. 状态指示（RGB，键盘层）

| 状态 | 颜色 |
|---|---|
| Insert | 绿 |
| **Insert（`Normal --Esc--> Insert` 后 3s 内）** | **橙**（键盘可配置；见下） |
| Normal（空闲） | 蓝 |
| Normal 多键 pending（计数/操作符/缩进/`g`/`Z` 待结束） | 黄 |
| Visual（`v`） | 紫 |
| **Visual-Line（`V`）** | **洋红 rose** |

| 鼠标模式 | 青（cyan） |
| vim 关闭 | 红 |

> pending 黄**不覆盖** Visual / Visual-Line：两种可视模式都不显示黄
> （Visual 内**没有**多键 pending：非法键直接吞键；计数累积也不算 pending，见 §7）。
> **Visual 紫（`#800080`）与 Visual-Line 洋红 rose（`#FF0080`）是两种颜色**，用于区分字符选与行选。
>
> **回到打字提示（橙）**：`Normal` 空闲按 `Esc` 回到 `Insert` 后 **3 秒内**，模式色由 Insert 绿**替换**为
> 键盘配置的提示色（两键盘均为橙 `#FF8000`），3 秒后自动回到 Insert 绿。
> 判据见 `design.md` §4.12：`vim_insert_flash()`（**vim 开 + 模式为 Insert + Esc 宽限窗口未过期**）
> 与 `vim_insert_flash_color(&r,&g,&b)`（把判据与 `cfg.insert_flash_color` 一起裁决，色值 `0` = 不覆盖）。
> 窗口计时用 **32 位** timer：QMK `timer_read()` 是 16 位，在 65536ms 处回绕会让已过期的窗口"复活"
> （持续打字 65.5s 后 3s 假亮橙），故宽限窗口一律 `timer_read32()/timer_elapsed32()`。
> 该窗口**只**由「Normal 空闲 `Esc` 回到 Insert」开启（窗口内再按 `Esc` 会重置计时，橙色随之续期）；
> 其余进入 Insert 的路径（开机、`Caps` 开启 vim、`i`/`a`/`o`/`s`/`c` 等编辑命令）**不亮橙**；
> Normal / Visual / 鼠标模式 / vim 关闭一律不亮橙。

## 11. 不提供的功能

出于"纯键码、键盘无关"的限制，以下**不提供**：

- 文本对象（`iw`/`aw`/`i"` 等）——需要识别文本边界；
- 搜索 / 查找 / 标记（`/ ? n N f t * # %`、`m`、反引号/单引号跳转等）——需要读文本；
- `@` 宏 / 寄存器 / `"` 前缀 / `Ctrl+R` 带寄存器；
- 窗口命令、命令行 `:`；
- 替换模式 `R`；`NG`（跳转第 N 行）；
- 段落移动 `{}`、屏幕行 `gj/gk/gJ`。

原因：键盘只能发送键码，无法读取/判断编辑器缓冲区内容；上述命令要么需要读文本，
要么依赖具体编辑器行为。其余**非 vim 键码**一律原样透传。

> 注：引擎**禁用阻塞式 `wait_ms`**（emit 走非阻塞队列）；仅键盘层的保命流程（如原厂 bootloader 组合键）可例外使用 `wait_ms`。
